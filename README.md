# Employee Analytics Dashboard – Power BI

## 📊 Project Overview

This project is an interactive Employee Analytics Dashboard developed using Microsoft Power BI.

The dashboard analyzes employee data to provide insights into workforce structure, employee demographics, salary distribution, departments, and other key employee metrics.

## 🛠️ Tools & Skills

- Microsoft Power BI
- Power Query
- Data Cleaning
- Data Transformation
- Data Modeling
- DAX
- KPI Creation
- Data Visualization
- Interactive Dashboard Design

## 📁 Project Files

- `Project.pbix` – Power BI dashboard and complete analysis file.

## 🔍 Analysis Performed

- Employee count analysis
- Department-wise employee analysis
- Salary analysis
- Employee demographic analysis
- KPI analysis
- Interactive filtering using slicers
- Data cleaning and transformation using Power Query
